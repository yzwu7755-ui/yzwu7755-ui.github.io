AI 智能体调优

大模型交互、提示词工程与知识库构建

这个站点的最大亮点不是静态展示，而是把个人经历转成可问答的候选人知识库，并通过 Serverless API 接入免费大模型，实现低成本、可维护、可追问的个人智能体。

01 / Interaction

大模型交互链路

前端收集 HR 的自然语言问题，经 Cloudflare Worker 统一做 CORS、限流、密钥注入、知识库装配和模型调用，再把回答返回到页面。前端不保存 API Key，本地打开 index.html 也能通过 Worker 直接调试。

02 / Prompt

提示词工程优化

提示词按“角色目标、回答策略、事实边界、回答自检、知识库”组织，约束模型先给结论、避免编造、按问题选择 STAR / 技术栈 / 岗位匹配等结构化回答。

03 / Knowledge Base

Markdown 知识库

个人优势、专业技能、工作内容、工作业绩和核心项目拆成 profile/*.md，方便后续持续维护；Worker 从 GitHub Pages 拉取并缓存，避免把全部知识写死在 JS 里。

04 / Guardrails

免费额度与事实保护

模型固定使用 free 模型，设置 max_price = 0，并通过单 IP 每日配额控制调用频次；回答时只基于知识库数字和事实，不补充未提供的公司名、奖项或联系方式。
