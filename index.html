Site Architecture

个人站点架构

这个站点使用纯静态前端 + Cloudflare Worker + OpenRouter 免费模型，避免购买服务器，也避免在前端暴露 API Key。

01

技术栈

GitHub Pages HTML / CSS / JavaScript Cloudflare Worker OpenRouter Free Static Config STAR Prompt
02

请求链路

  1. HR 打开 GitHub Pages 静态页面
  2. 浏览器请求 Cloudflare Worker
  3. Worker 使用 Secret 中的 OpenRouter Key
  4. OpenRouter Free 模型生成回答
  5. Worker 返回结果给个人 Agent 聊天框
03

部署步骤

GitHub Pages / root Cloudflare Worker API OpenRouter Secret config.js endpoint
04

API Key 申请

  1. 注册 OpenRouter
  2. 创建 API Key
  3. 不要把 Key 写进 GitHub Pages
  4. 只放入 Cloudflare Worker Secret
05

免费额度保护

  • 模型固定为 `openrouter/free`
  • 拒绝非免费模型
  • 设置 `max_price` 为 0
  • 单 IP 每日 20 次
  • 建议 OpenRouter 不开启自动充值
