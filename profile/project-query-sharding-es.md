# 项目：订单分库分表与 ES 统一查询平台

## 项目简介

针对订单查询链路性能瓶颈与数据规模增长问题，推动单库架构向分库分表 + ES 的分布式查询体系演进。

构建高性能、高可用的统一查询平台，支撑大规模数据与高并发查询场景。

## 技术栈

- Spring Cloud
- Spring Boot
- MyBatis
- MySQL
- Redis
- Elasticsearch
- Kafka
- Canal
- XXL-JOB
- Apollo
- Maven

## 职责与成果

### 1. 分库分表架构设计与数据迁移

设计并落地分库分表架构，完成 5.7TB 单库向 MySQL 集群（64 库 × 16 表）平滑迁移。

将单表规模由亿级降至百万级，显著提升查询性能与 DDL 效率，整体存储成本下降 20% ~ 30%。

### 2. 分布式订单 ID 升级

主导分布式订单 ID 升级方案落地，基于雪花算法实现全局唯一、趋势递增的分布式 ID（Int → Long）。

采用 SDK 本地生成 + Redis WorkerId 动态分配与续租，保障多节点下的唯一性与高并发稳定生成。

该方案支撑分库分表场景，并解决原有订单 ID 容量瓶颈。

### 3. 分布式查询模型优化

设计“分片分组 + 批量查询 + 有界并发”查询模型，将逐单查询优化为分片级查询。

减少无效扫描与资源浪费，稳定支撑 10W+ QPS 高并发访问。

### 4. Binlog + MQ 双链路同步

构建 Binlog（Canal）+ 业务 MQ 双链路同步机制，实现订单数据秒级写入 Elasticsearch。

通过重试队列 + 指数退避策略处理异常写入，提升链路稳定性并保障最终一致性。

### 5. 统一 ES 查询服务

构建统一 ES 查询服务，支持多条件组合与模糊检索等复杂查询场景，显著降低数据库压力。

设计查询降级与容灾机制，在 ES 异常时可平滑切换至备用数据源，系统可用性达到 99.999%+。

### 6. 数据一致性校验闭环

建立“准实时 + 离线”双模式对账机制，构建 ES 与 DB 数据一致性校验闭环，保障最终一致性与链路可靠性。

### 7. 分布式扫描与迁移

基于 XXL-JOB + Redis 实现分库分表下的分布式扫描与并发控制（游标推进 + 限流）。

完成 10 亿级 DB 数据到 ES 的平滑迁移，峰值达到 2 亿 / 天。

### 8. 查询模板标准化与智能化

建设查询模板标准化与智能化体系，抽象 100+ 查询场景。

其中 70% 收敛为 3 类通用模板，其余沉淀约 30 个定制模板。

结合 AI 构建查询 Skill，支持自然语言生成查询与参数校验，降低重复开发成本并提升接入效率。
