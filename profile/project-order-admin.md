# 项目一：订单管理站点建设与全栈升级

## 项目背景

订单管理站点是面向客服、运营、履约、财务及技术支持等内部角色的统一订单操作平台，承载订单查询、详情展示、状态处理、履约操作、异常审核及售后协同等核心功能。

随着业务规模增长，原有站点存在功能入口分散、权限粒度较粗、前后端交互不统一、重复页面建设较多以及敏感操作管控不足等问题，难以满足多角色、多业务场景下的精细化管理需求。

## 项目描述

主导订单管理站点的全栈建设与持续迭代，负责需求调研、业务流程梳理、技术方案设计、任务拆解、前后端开发、联调测试、灰度发布及上线保障。

后端基于 Java、Spring Boot、MyBatis 等技术建设订单查询与操作接口；前端基于 Vue3、TypeScript、Element Plus 完成订单列表、订单详情、审核处理、配置管理等页面开发，具备从数据库、接口到前端交互的完整交付能力。

围绕不同岗位和业务场景建设统一权限体系，基于“用户—角色—菜单—按钮—数据范围”模型，实现页面访问、操作按钮、接口调用及订单数据范围的多层权限控制。

针对订单取消、状态变更、退款审核等敏感操作，增加权限校验、二次确认、操作原因填写及审计日志，确保关键操作可控制、可追踪、可审计。

同时沉淀统一查询表单、列表表格、详情卡片、状态标签、权限指令及异常提示等前端公共组件，统一接口返回、分页查询及异常处理规范，减少重复开发，提升订单管理类需求的交付效率和站点使用体验。

## 技术栈

- Java
- Spring Boot
- MyBatis
- MySQL
- Vue3
- TypeScript
- Element Plus
- Axios
- RBAC 权限模型

## 个人职责

- 负责订单管理站点整体业务和技术方案设计，完成概要设计、详细设计及核心模块拆解，推动产品、测试及上下游团队协同落地。
- 负责订单列表、订单详情、操作审核、规则配置等页面的全栈开发，独立完成数据库设计、后端接口、前端页面及前后端联调。
- 建设基于角色的权限控制体系，实现菜单权限、按钮权限、接口权限及数据权限统一管理。
- 对取消订单、状态修改、审核通过等高风险操作增加权限校验、操作确认及审计记录，降低越权和误操作风险。
- 设计统一的订单查询接口和页面模型，支持多条件组合查询、分页展示、详情联动及状态动态渲染。
- 抽象表单、表格、弹窗、状态展示及权限控制等前端通用组件，提升页面复用性和前端开发效率。
- 负责站点性能优化、异常处理、灰度发布及线上问题排查，保障核心订单操作稳定运行。

## 项目成果

- 建设统一订单管理入口，整合分散的订单查询、详情查看、状态处理及审核操作能力，为客服、运营、履约等多个团队提供统一作业平台，降低跨系统切换和人工沟通成本。
- 完善订单权限管理体系，建立覆盖菜单、按钮、接口及数据范围的多层权限控制机制，实现不同角色按职责访问和操作订单，降低敏感订单数据泄露、越权操作及误操作风险。
- 实现关键操作全链路审计，针对取消订单、状态变更、审核处理等高风险操作记录操作人、操作时间、变更内容及操作原因，提高问题定位和责任追溯效率。
- 提升全栈需求交付效率，独立完成多个订单管理功能从需求分析、数据库设计、Java 接口开发到 Vue 前端页面交付，减少前后端协作等待时间，提升业务需求响应速度。
- 沉淀前端公共组件与开发规范，抽象查询表单、数据表格、订单详情、状态标签、权限指令及通用弹窗等能力，减少重复页面开发，提升站点一致性和可维护性。
- 统一前后端交互规范，规范分页、参数校验、异常码及提示信息，降低接口理解和联调成本，提高线上问题排查效率。
- 支撑数百个订单业务迭代需求，覆盖订单查询、履约处理、异常审核及运营配置等核心场景，保障业务需求高质量、按期交付。
- 持续优化订单查询与页面性能，通过查询条件治理、接口聚合、异步加载及页面按需渲染等方式，提升复杂订单详情和列表页面的响应速度及操作体验。
- 保障站点稳定运行，通过分阶段灰度、权限验证、数据核对、监控告警及快速回滚机制，降低改造对线上客服和运营作业的影响。
- 形成完整的全栈交付能力，具备从业务建模、后端架构、权限设计到前端页面和用户交互的端到端建设经验，推动订单管理站点由功能型后台向标准化、平台化管理系统演进。

## STAR 摘要

- Situation：订单管理入口分散、权限粒度粗、重复页面多，难以支撑多角色精细化管理。
- Task：主导建设统一订单管理站点，完成全栈升级、权限体系、审计能力和公共组件沉淀。
- Action：基于 Java + Spring Boot + MyBatis 建设后端接口，基于 Vue3 + TypeScript + Element Plus 开发前端页面，并落地多层权限、审计日志、统一交互规范和灰度发布机制。
- Result：形成统一订单作业平台，支撑数百个订单业务迭代需求，提升全栈交付效率、站点一致性、可维护性和操作安全性。
