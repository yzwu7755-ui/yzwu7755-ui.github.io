# 专业技能

## Java 基础

熟练使用 Java，扎实掌握集合、IO、反射、动态代理、泛型等基础知识。

深入理解并发编程，掌握 JMM、`synchronized`、`volatile`、CAS、AQS、`ThreadLocal`、线程池等核心机制。

熟悉 JVM 类加载机制、内存模型、垃圾回收（G1、CMS）及常见性能调优方法。

## Spring 生态

熟练使用 Spring、Spring Boot、Spring MVC、MyBatis、MyBatis-Plus 等主流框架。

理解 IOC、AOP、事务管理、自动装配等核心原理，具备框架扩展及二次开发经验。

## 微服务架构

熟悉 Spring Cloud Alibaba 微服务体系，掌握 Nacos、OpenFeign、Sentinel、Gateway 等组件。

具备服务治理、限流、熔断、降级及灰度发布等实践经验。

## 数据库

熟悉 MySQL 底层原理，掌握索引、事务、MVCC、锁机制、Undo Log、Redo Log、Binlog 等知识。

具备 SQL 调优、索引优化、分库分表、海量数据治理及数据迁移经验。

## 缓存与中间件

熟悉 Redis 线程模型及数据结构，掌握缓存设计、分布式锁、延迟队列、缓存一致性等方案。

熟悉 Kafka、RabbitMQ 等消息中间件，具备消息可靠性、顺序消息、重复消费、消息堆积治理等实践经验。

## 搜索与大数据

熟练使用 Elasticsearch，掌握索引设计、Mapping、DSL 查询、Mustache 模板、数据同步（Binlog + MQ）、一致性校验等能力。

具备海量订单异构查询平台建设经验。

## 分布式技术

熟悉 CAP、BASE 等分布式理论。

掌握 TCC、Seata、2PC 等分布式事务方案，具备分布式 ID、分布式锁、高并发、高可用系统设计及稳定性治理经验。

## 前端开发

具备 Java 全栈开发能力，熟练使用 Vue3、TypeScript、JavaScript、Element Plus、Axios 等技术栈。

能够独立完成管理后台从页面开发、组件封装、权限控制到前后端联调的完整交付。

熟悉 Vite、npm、Pinia 等前端工程化工具。

## 设计与架构

熟悉常用设计模式及领域建模思想。

在实际项目中应用单例、工厂、代理、策略、模板方法、责任链、观察者等设计模式。

具备平台化、组件化及公共能力抽象经验。

## AI 工程能力

熟练使用 Cursor、GitHub Copilot、Claude Code 等 AI 编程工具进行代码生成、重构、单元测试及全栈开发。

掌握 Prompt Engineering、Token、Function Calling 等大模型基础。

熟悉 MCP（Model Context Protocol）、Agent、Tool Calling、RAG 等技术，具备 Skill 开发经验。

了解 Spring AI、LangChain4j 等 Agent 开发框架，可基于 LLM 构建智能业务应用。
