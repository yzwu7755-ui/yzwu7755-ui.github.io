# Agent 知识库说明

本目录为个人 Agent 的候选人知识库，建议大模型按以下顺序读取：

1. `personal-advantages.md`：个人优势、技术标签、候选人核心画像。
2. `work-content.md`：工作职责、项目范围、核心系统建设内容。
3. `work-achievements.md`：工作业绩、量化结果、可用于 STAR 回答的成果事实。

回答规则：

- 回答必须基于知识库，不要编造公司、学历、奖项或数据。
- 当 HR 询问候选人优势时，优先参考 `personal-advantages.md`。
- 当 HR 询问日常工作、项目职责、系统设计时，优先参考 `work-content.md`。
- 当 HR 询问业绩、影响力、量化结果、STAR 案例时，优先参考 `work-achievements.md`。
- 如果资料不足，应明确说明“目前知识库没有提供该信息”。
