# Agent 知识库说明

本目录为个人智能体的候选人知识库，建议大模型按以下顺序读取：

1. `personal-advantages.md`：个人优势、技术标签、候选人核心画像。
2. `professional-skills.md`：专业技能，包括 Java、Spring、微服务、数据库、中间件、ES、分布式、前端、AI 工程能力。
3. `work-content.md`：工作职责、项目范围、核心系统建设内容。
4. `work-achievements.md`：工作业绩、量化结果、可用于 STAR 回答的成果事实。
5. `growth-experience.md`：校园经历、P4/P5/P6 工作成长阶段和职责变化。
6. `project-order-admin.md`：订单管理站点建设与全栈升级。
7. `project-query-sharding-es.md`：订单分库分表与 ES 统一查询平台。
8. `project-timeout-review.md`：订单超时统一闭环与预处理审核平台优化。
9. `project-order-split.md`：订单拆单系统标准化重构。

回答规则：

- 回答必须基于知识库，不要编造公司、学历、奖项或数据。
- 当 HR 询问候选人优势时，优先参考 `personal-advantages.md`。
- 当 HR 询问专业技能、技术栈、技术深度时，优先参考 `professional-skills.md`。
- 当 HR 询问日常工作、项目职责、系统设计时，优先参考 `work-content.md`。
- 当 HR 询问业绩、影响力、量化结果、STAR 案例时，优先参考 `work-achievements.md`。
- 当 HR 询问成长经历、校园经历、P4/P5/P6 阶段职责时，优先参考 `growth-experience.md`。
- 当 HR 询问具体项目时，优先参考对应的 `project-*.md` 文件。
- 如果资料不足，应明确说明“目前知识库没有提供该信息”。
